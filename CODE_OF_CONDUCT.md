# Code of conduct

Levuche is built in the open so that creators, buyers and developers can see how it works and help make it better. Everyone who takes part in Levuche's repositories, issues, discussions and pull requests is expected to help keep them a place people want to come back to.

## What we expect

- Be kind and patient, and assume good intent.
- Disagree with ideas, not with people.
- Stay on topic and keep each issue or discussion to one subject.
- Respect privacy: don't post anyone's personal details, account data, orders or private messages, your own included.
- Report security problems privately ([SECURITY.md](SECURITY.md)), never in public.

## What isn't allowed

- Harassment, insults, threats or personal attacks.
- Discriminatory language or jokes.
- Sexual content or unwelcome attention.
- Spam, advertising, or posting the same thing in many places.
- Publishing someone else's private information.
- Malware, attacks on live systems, or stolen data.

## What maintainers do

The Levuche maintainers may edit, hide, lock or delete comments, issues, discussions and pull requests that break this code, and may block someone from the Levuche organization on GitHub, for a time or for good. We'll usually explain why, unless explaining would put someone at risk.

## Reporting

To report a comment, issue or discussion, use **Report content** in its **...** menu on GitHub, which reaches GitHub and the maintainers. For anything else, contact Jagodana LLC, which runs Levuche, through [jagodana.com](https://jagodana.com). Reports are read by the maintainers only and kept private.

## Scope

This code applies in all of Levuche's spaces on GitHub, and wherever someone represents Levuche in public.
